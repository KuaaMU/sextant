# Sextant UI Design v1.0

## 一、设计原则（不变量）

| 原则 | 具体约束 |
|------|---------|
| 4±1 组块 | 主界面同时呈现的信息组块不超过 5 个 |
| 3 秒决策 | 任何需要人类介入的场景，必须在 3 秒内完成「同意/修改/否决」 |
| 95% 静默 | 系统在 95% 时间自主运行，UI 不打扰 |
| 直觉隐喻 | 航海仪表盘（海图、船员、船体、舵轮）替代量化术语 |
| 渐进信任 | 系统根据历史准确率自动提升授权，用户无感知放手 |

## 二、隐喻系统

| 抽象概念 | 直觉隐喻 | 用户操作 |
|---------|---------|---------|
| Agent Swarm | AI 船员（瞭望手、舵手、领航员、记录员） | 看状态灯、点名字查岗 |
| 市场状态 | 海况天气（风浪、洋流、能见度） | 看中央海图 |
| 风险场 | 船体耐压（船壳完整性） | 看仪表指针 |
| 交易意图 | 船员报告（「建议左满舵避礁」） | 卡片式确认 |
| 自主权 | 自动驾驶档位 | 滑杆拖拽 |
| 策略进化 | 船只升级（换更好的帆/罗盘） | 升级按钮 |

## 四、核心交互模式

### 4.1 Intent Card（意图卡片）

当 Agent 要执行交易时，右侧滑入一张卡片：

```
┌─────────────────────────────┐
│  🤖 舵手 (Strategy Agent)    │
│  置信度: ● 高                │
│                             │
│  「建议减仓 BTC 30%」         │
│                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━    │
│  原因: 洋流逆转 + 前方浅滩     │
│  风险: ████░░░░░ 温和        │
│  执行: TWAP 分 3 笔           │
│  预计: 2.3 分钟完成           │
│  ━━━━━━━━━━━━━━━━━━━━━━━    │
│                             │
│  [✓ 同意]  [✏️ 改参数]  [✗ 否] │
│                             │
│     ⏱️ 18s 后自动同意         │
└─────────────────────────────┘
```

- [✓ 同意] → 立即执行
- [✏️ 改参数] → 展开微调面板
- [✗ 否] → 卡片变红归档
- 倒计时：默认 30s，悬停暂停，全局可调

### 4.2 Agent 轨道栏

底部常驻，每个 Agent 一个单元格：

| 元素 | 规范 |
|------|------|
| 状态灯 | 12px 圆形，左上角：🟢正常 🟡建议 🔴异常 🌀思考 ⚪离线 |
| 名称 | 14px，"瞭望手"/"舵手"/"领航员"/"记录员" |
| 当前任务 | 单行截断，12px，"正在扫描订单簿..." |
| 进度条 | 底部 3px 细条，颜色随状态 |

### 4.3 海图（Market 面板）

不是 K线，而是：

- **颜色** = 波动率（蓝 `#0EA5E9` → 绿 `#10B981` → 黄 `#F59E0B` → 红 `#EF4444`）
- **线条粗细** = 流动性深度（1px < $1M → 4px + 发光 > $50M）
- **箭头** = 价格动量方向
- **当前位置** = 闪烁点
- **预测轨迹** = 虚线（Strategy Agent 输出）

### 4.4 风险仪表（Risk 面板）

6 个圆形仪表，每个 120px 直径：

```
    ╭──────╮
   ╱   72   ╲
  │  ──────  │
  │ /      \ │
  ││ 🟢安全  ││
  │ \      / │
   ╲  ────  ╱
    ╰──────╯
  风险值: 0.72
  阈值: 0.80
  梯度: ↗ 0.12/tick
```

- 三色分区：绿(0-0.6) / 黄(0.6-0.8) / 红(0.8-1.0)
- 指针靠近红色区 → 边框脉冲
- 点击 → 展开 24h 趋势

## 五、渐进授权

| 级别 | 名称 | 行为 |
|------|------|------|
| 手动 | 所有意图必须人工确认 | 倒计时 ∞ |
| 辅助 | 高置信 30s 倒计时，低置信暂停 | 默认档位 |
| 自动 | 高置信自动通过，仅紧急阻塞 | 信任分 > 0.9 |
