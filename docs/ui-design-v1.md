# Sextant UI Design v1.1

## 一、设计原则（不变量）

| 原则 | 具体约束 |
|------|---------|
| 4±1 组块 | 主界面同时呈现的信息组块不超过 5 个 |
| 3 秒决策 | 任何需要人类介入的场景，必须在 3 秒内完成「同意/修改/否决」 |
| 95% 静默 | 系统在 95% 时间自主运行，UI 不打扰 |
| 直觉隐喻 | 航海仪表盘（海图、船员、船体、舵轮）替代量化术语 |
| 渐进信任 | 系统根据历史准确率自动提升授权，用户无感知放手 |

## 二、隐喻系统

| 抽象概念 | 直觉隐喻 | 用户操作 |
|---------|---------|---------|
| Agent Swarm | AI 船员（瞭望手、舵手、领航员、记录员） | 看状态灯、点名字查岗 |
| 市场状态 | 海况天气（风浪、洋流、能见度） | 看中央海图 |
| 风险场 | 船体耐压（船壳完整性） | 看仪表指针 |
| 交易意图 | 船员报告（「建议左满舵避礁」） | 卡片式确认 |
| 自主权 | 自动驾驶档位 | 滑杆拖拽 |
| 策略进化 | 船只升级（换更好的帆/罗盘） | 升级按钮 |
| 策略管理 | 船员编制（谁干什么、参数多少） | 策略工坊面板 |
| 执行历史 | 航海日志（去过哪、赚了多少） | 日志面板 |
| 回测 | 模拟航行（不花钱试航线） | 研究面板 |

## 四、核心交互模式

### 4.1 Intent Card（意图卡片）

当 Agent 要执行交易时，右侧滑入一张卡片（300ms ease-out 动画）：

```
┌─────────────────────────────┐
│  🤖 舵手 (Strategy Agent)    │
│  置信度: ● 高  85%           │
│                             │
│  「建议减仓 BTC 30%」         │
│                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━    │
│  原因: 洋流逆转 + 前方浅滩     │
│  风险: ████░░░░░ 温和        │
│  执行: TWAP 分 3 笔           │
│  预计: 2.3 分钟完成           │
│  ━━━━━━━━━━━━━━━━━━━━━━━    │
│                             │
│  [✓ 同意]  [✏️ 改参数]  [✗ 否] │
│                             │
│     ⏱️ 18s 后自动同意         │
│     ████████░░░░ 60%        │
└─────────────────────────────┘
```

- [✓ 同意] → 立即执行
- [✏️ 改参数] → 展开微调面板（价格、数量、执行方式）
- [✗ 否] → 卡片变红归档
- 倒计时：默认 30s，悬停暂停，全局可调
- **底部进度条**：倒计时可视化，颜色从绿→黄→红

### 4.2 Agent 轨道栏

底部常驻，每个 Agent 一个单元格：

| 元素 | 规范 |
|------|------|
| 状态灯 | 12px 圆形，呼吸脉冲动画：🟢正常 🟡建议 🔴异常 🌀思考 ⚪离线 |
| 名称 | 14px，"瞭望手"/"舵手"/"领航员"/"记录员" |
| 当前任务 | 单行截断，12px，"正在扫描订单簿..." |
| 进度条 | 底部 3px 细条，颜色随状态 |
| 点击 | 展开该 Agent 详情（最近 10 条决策 + 性能统计） |

### 4.3 海图（Market 面板）

不是 K线，而是流动性 + 波动率可视化：

- **背景色块** = 波动率温度（蓝 `#0EA5E9` → 绿 `#10B981` → 黄 `#F59E0B` → 红 `#EF4444`）
- **流动线条** = 流动性主力方向，粗细映射深度（1px < $1M → 4px > $50M）
- **当前位置** = 闪烁光点
- **预测轨迹** = 虚线（Strategy Agent 输出）

### 4.4 风险仪表（Hull Integrity）

6 个圆形仪表，每个 120px 直径，Painter 手绘：

```
    ╭──────╮
   ╱   72   ╲
  │  ──────  │
  │ /      \ │
  ││ 🟢安全  ││
  │ \      / │
   ╲  ────  ╱
    ╰──────╯
  风险值: 0.72
  阈值: 0.80
  梯度: ↗ 0.12/tick
```

- 三色弧：绿(0-0.6) / 黄(0.6-0.8) / 红(0.8-1.0)
- 指针靠近红色区 → 边框脉冲动画
- 点击 → 展开 24h 趋势折线图

## 五、渐进授权

| 级别 | 名称 | 行为 | UI 表现 |
|------|------|------|---------|
| 手动 | 所有意图必须人工确认 | 倒计时 ∞ | 滑杆最左，卡片无倒计时 |
| 辅助 | 高置信 30s 倒计时，低置信暂停 | 默认档位 | 滑杆中间，卡片有倒计时 |
| 自动 | 高置信自动通过，仅紧急阻塞 | 信任分 > 0.9 | 滑杆最右，卡片自动消失 |

## 七、技术架构

### 7.1 技术栈

```
eframe (native window, glow backend)
 └── egui (immediate mode)
      ├── egui_plot (折线图，IR 曲线)
      ├── egui::Painter (手绘自定义组件)
      └── 自定义 painter 模块
           ├── animation.rs (动画系统：tween、pulse、slide)
           ├── shapes.rs (圆形仪表、热力图、流动线条)
           └── sea_chart.rs (海图专用绘制)
```

### 7.2 数据流

```
sextant-live
  ├── encoder.push_event() ──→ sextant_events.mmap ──→ ExtendedSource ──→ GuiState
  └── event_callback() ──→ ws://localhost:8765/ws ──→ WebSocket 客户端
```

### 7.3 动画系统

```rust
// 一次性动画（滑入、淡入）
Animation { start_time, duration, easing, from, to }
  → value(now) → 插值结果
  → is_finished(now) → 是否完成

// 持续动画（脉冲、呼吸灯）
Pulse { period, min, max }
  → value(now) → 当前值

// 滑入动画
SlideIn { animation, width }
  → offset_x(now) → X 偏移量
```
